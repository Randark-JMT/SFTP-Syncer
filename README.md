# SFTP Syncer

一个使用 Go 编写的 Windows GUI SFTP 同步工具，支持多主机管理与并行同步。

## 功能

- **主机管理器**：添加主机后参数自动记忆（持久化到用户配置目录），主窗口以列表方式管理多台主机，添加/编辑主机时弹出独立的配置对话框
- **多主机并行同步**：可单独开始/停止某台主机，也可「全部开始/全部停止」，各主机拥有独立的连接与下载 Worker 池，互不干扰
- 支持选择 **密码认证** 或 **私钥认证**（私钥口令可选）
- 递归扫描远程目录，并保留原有目录结构下载到本地
- 枚举时跳过以点（`.`）开头的目录（如 `.git`、`.ssh`），整个子树不做扫描；远程根目录本身以点开头时不受影响
- 仅处理 **远程文件 UTC 修改时间早于当前时间 30 分钟** 的常规文件
- 下载成功后删除远程源文件
- 任务表格按主机显示每个文件的下载状态、进度与速度
- 最小化或关闭窗口后隐藏到系统托盘，而不是继续占用任务栏

## 使用说明

1. 启动程序后点击「添加主机…」，在弹出的对话框中填写：
   - 名称（可选，用于区分主机）
   - 服务器地址、端口、用户名
   - 认证方式：密码 或 私钥
   - 远程目录、本地目录、轮询间隔（秒）
   - 如需跳过主机密钥校验，可保持“跳过主机密钥校验”勾选
2. 点击「确定」后主机即保存并出现在主窗口的主机列表中；双击列表中的主机可随时编辑，运行中的主机需先停止才能编辑或删除。
3. 选中主机后点击「开始同步」立即执行一轮扫描并按轮询间隔持续运行；点击「全部开始」可同时启动所有主机。
4. 任务表格实时显示各主机当前下载任务；日志区按主机前缀记录运行情况。
5. 当窗口最小化或点击右上角关闭时，程序会隐藏到系统托盘：
   - 左键托盘图标：恢复窗口
   - 右键托盘图标：退出程序

## 配置文件位置

程序会把主机列表保存到用户配置目录下：

- Windows：`%AppData%\SFTP-Syncer\hosts.json`

> 旧版本的单主机 `config.json` 会在首次启动新版本时自动迁移为 `hosts.json` 中的一条主机记录，原文件保持不变。

> 当前版本会把密码或私钥相关配置保存到本地配置文件中，以便下次启动自动填充。若你对安全要求较高，建议后续改造为 Windows Credential Manager 或更安全的密钥托管方式。

## 构建

开发调试构建：

`go build ./...`

生成 Windows GUI 可执行文件（不显示控制台窗口）：

`go build -ldflags="-H windowsgui" -o SFTP-Syncer.exe .`

> **首次构建前必须先生成资源文件**：可执行文件需要嵌入 `app.manifest`（声明 comctl32 v6 依赖），否则 GUI 初始化会失败（`TTM_ADDTOOL failed`）。仓库的 `.gitignore` 忽略了 `*.syso`，克隆后请先执行一次：
>
> `go run github.com/akavel/rsrc@latest -manifest app.manifest -arch amd64 -o rsrc_windows_amd64.syso`
>
> 之后 `go build` 会自动把生成的 `rsrc_windows_amd64.syso` 链接进可执行文件。修改 `app.manifest` 后同样需要重新生成。

## 备注

- 主机时间判断统一使用 UTC。
- 为避免与远程仍在写入的文件竞争，程序只会处理早于当前时间 30 分钟的文件。
- 如果下载成功但远程删除失败，该文件会保留在本地，下一轮仍可能再次尝试处理远程文件。
- 每台主机使用独立的 SSH 连接池（4 个下载 Worker）；多主机并行时总连接数为各主机之和。
