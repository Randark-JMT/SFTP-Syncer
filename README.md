# SFTP Syncer

一个使用 Go 编写的 Windows GUI SFTP 同步工具。

## 功能

- 图形界面配置 SFTP 服务器、本地目录、远程目录与轮询间隔
- 支持选择 **密码认证** 或 **私钥认证**（私钥口令可选）
- 递归扫描远程目录，并保留原有目录结构下载到本地
- 仅处理 **远程文件 UTC 修改时间早于当前时间 30 分钟** 的常规文件
- 下载成功后删除远程源文件
- 最小化或关闭窗口后隐藏到系统托盘，而不是继续占用任务栏
- 配置自动保存到当前用户配置目录

## 使用说明

1. 启动程序后填写以下信息：
   - 服务器地址
   - 端口
   - 用户名
   - 认证方式：密码 或 私钥
   - 如果选择密码认证：填写密码
   - 如果选择私钥认证：填写私钥文件路径；若私钥已加密，可额外填写私钥口令
   - 远程目录
   - 本地目录
   - 轮询间隔（秒）
2. 如需跳过主机密钥校验，可保持“跳过主机密钥校验”勾选。
3. 点击“开始同步”后，程序会立刻执行一轮扫描，并按照轮询间隔持续运行。
4. 当窗口最小化或点击右上角关闭时，程序会隐藏到系统托盘：
   - 左键托盘图标：恢复窗口
   - 右键托盘图标：退出程序

## 配置文件位置

程序会把配置保存到用户配置目录下：

- Windows：`%AppData%\SFTP-Syncer\config.json`

> 当前版本会把密码或私钥相关配置保存到本地配置文件中，以便下次启动自动填充。若你对安全要求较高，建议后续改造为 Windows Credential Manager 或更安全的密钥托管方式。

## 构建

开发调试构建：

`go build ./...`

生成 Windows GUI 可执行文件（不显示控制台窗口）：

`go build -ldflags="-H windowsgui" -o SFTP-Syncer.exe .`

## 备注

- 主机时间判断统一使用 UTC。
- 为避免与远程仍在写入的文件竞争，程序只会处理早于当前时间 30 分钟的文件。
- 如果下载成功但远程删除失败，该文件会保留在本地，下一轮仍可能再次尝试处理远程文件。
